# Indian Fact-Check Explorer

An exploratory data analysis and machine learning project examining patterns in fact-checking articles related to India.

## Project Overview

This project explores a dataset of fact-checking articles to understand publication trends, topic distributions, article characteristics, and the availability of social media references.

## Objectives

- Analyze fact-checking publication trends over time.
- Explore article topics and content characteristics.
- Examine differences across fact-checking outlets.
- Investigate the availability of social media links.
- Experiment with NLP techniques, topic modeling, and text classification.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF and topic modeling
- Statistical hypothesis testing

## Project Files

- `indian-fact-checking-analysis-eda-nlp-machine.ipynb` — analysis, visualizations, statistical tests, NLP, and machine learning experiments.

## Dataset

Source: [Precog Research Group — Datasets](https://precog.iiit.ac.in/datasets/)

## Limitations

The dataset contains collected fact-checking articles rather than all claims circulating online. Topic labels are incomplete and should not be interpreted as true/false verdicts. Results describe patterns within this dataset and should not be generalized to all misinformation or all fact-checking activity in India.

## Future Scope

- Improve model evaluation using more robust data splits.
- Explore retrieval-augmented generation (RAG) for fact-checking research.

## Disclaimer

This project is intended for educational and research purposes. It does not independently verify the truth of claims.
